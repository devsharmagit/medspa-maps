## Why three files stay at the repository root

`AGENTS.md`, `CLAUDE.md` and `GEMINI.md` are **discovered by exact name at the repo root** — moving
them into `docs/` would silently stop every AI assistant from loading the project's rules.

- `AGENTS.md` is the vendor-neutral open standard (a Linux Foundation AAIF project). It is the
  **single source of truth** — put new agent rules there, never in the pointer files.
- `CLAUDE.md` and `GEMINI.md` are thin pointers to it, as are `.cursor/rules/medspa-maps.mdc`,
  `.windsurf/rules/medspa-maps.md` and `.github/copilot-instructions.md`.
- `web/AGENTS.md` and `web/CLAUDE.md` are **nested scope** — agents read the nearest file up the
  tree, so those correctly take precedence for work inside `web/`.

Deeper cross-IDE context (current state, open problems, decisions, runbooks, credentials) lives in
a shared Obsidian vault outside the repo — see `AGENTS.md` for the path and the session protocol.
